# Explorer design

The agreed palette and typography take precedence over generic dashboard suggestions: slate #172c43, white #ffffff, background #f5f7fa, action blue #1d4ed8, escalation amber #78500a on #fff4d6, error red #a52722. Fira Sans carries the interface. Fira Code is reserved for JSON and commands. Fonts are bundled locally.

The comparison table is the primary evidence view. The plot supplements it. The distinctive interaction is inspecting runtime attempts beside the independent outcome, with original and final state beneath them. Test fixtures, real recordings, and live executions are explicitly labeled.

The design search returned a generic documentation/dark-theme pattern that did not fit the brief. Its palette was not adopted. The implementation follows the supplied light interface, visible focus, native tables, readable controls, reduced motion, and stacked mobile layout.

No decorative motion, hidden API dependency, or financial claim is used to fill an empty report.
