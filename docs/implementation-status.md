- Independent evaluator and forty generated consistency-checked tasks with separate scenario groups.

- Inventory reservation through the same runner and a loaded exported configuration.

- Static React Compare, Inspect, and Apply explorer with explicit scripted/example, recorded, and live states.
- Local browser checks, mobile screenshots, API health check, PostgreSQL integration checks, and GitHub CI including a successful Docker build.
- Free-hosting configuration, account templates, operational register, video outline, launch drafts, and weekly availability automation.

The current implementation passes 61 backend/integration tests and four browser tests. CI also verifies the production frontend build, generated contracts, and Docker build.
